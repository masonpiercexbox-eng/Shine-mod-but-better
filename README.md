# Shine Enhanced

A standalone client-side Fabric mod for Minecraft Java 26.3 that adds original ambient sparkle, pollen-like glints, sprint trails, swimming bubbles, and boat wake particles.

## Build and install

GitHub Actions builds the mod automatically when code is pushed. Open the **Actions** tab, choose **Build Shine Enhanced**, and download the **ShineEnhanced** artifact from a successful run. Extract the ZIP and place the JAR in your Minecraft 26.3 Fabric profile's `mods` folder. Install Fabric API for Minecraft 26.3 as well.

This is an original approximation of cinematic particle effects, not a copy of proprietary Shine assets. The first cloud build checks compatibility; if it fails, the Actions log will show what needs fixing.
